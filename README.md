# Cosmo Cats Intergalactic Marketplace - Data Bases

Spring Boot 4.1.1, Java 25, PostgreSQL, Liquibase, Spring Data JPA та Testcontainers.

## Частина 1. Проєктування бази даних і міграції Liquibase

Спроєктовано PostgreSQL-базу в 3NF із п’яти таблиць:

- `customers` — покупці та їхні унікальні email.
- `categories` — коди й назви категорій товарів.
- `products` — товари, поточні ціни, залишки, категорії та стан архівування.
- `orders` — покупець, унікальний номер, дата й статус замовлення.
- `order_details` — товари замовлення, кількість і ціна на момент оформлення.

Через Liquibase реалізовано версіоноване створення таблиць, sequence, зв’язків, індексів і перевірок цілісності. Додано унікальність email покупця, номера замовлення та назви товару в межах категорії. Окрема міграція додає архівування товарів зі збереженням історії покупок.

## Частина 2. Доступ до даних і бізнес-логіка зі Spring Data JPA

Реалізовано JPA-сутності, репозиторії та CRUD для товарів, категорій і замовлень. Сервісний шар використовує `@Transactional`. Оформлення, редагування позицій і скасування замовлень атомарно змінюють залишки. Песимістичні блокування захищають від конфліктів паралельних операцій.

Пагінація, курсорні вибірки, пошук, фільтрація та сортування товарів виконуються в БД. Через JPQL і projections реалізовано звіти про популярні товари, продажі за категоріями, виручку, найактивніших покупців і товари без продажів.

Для додаткових вимог реалізовано унікальність назви товару в категорії, Natural ID замовлення та projections із JPQL-фільтрацією й сортуванням.

## Частина 3. Інтеграційне тестування з Docker і Testcontainers та покриття коду

Налаштовано інтеграційні тести з PostgreSQL у Docker через Testcontainers. Перевірено міграції, CRUD, обмеження, пагінацію, фільтри, архівування, Natural ID, звіти, rollback і конкурентні зміни залишків.

За результатом запуску `clean verify` успішно пройшли **175 тестів**, без помилок і пропусків. Покриття JaCoCo становить **94,67% рядків** і **87,50% гілок**. У CI налаштовано перевірку мінімум **80% покриття рядків**.

Для запуску тестів потрібні JDK 25 і запущений Docker:

```powershell
.\mvnw.cmd clean verify
```

Для локального запуску застосунку:

```powershell
docker compose up -d --wait
.\mvnw.cmd spring-boot:run
```

Звіт покриття після збірки доступний у `target/site/jacoco/index.html`.
