# Lab 3 databases

Гілка: `lab3-databases`
Базова гілка: `lab-2-tests`
Стан: локальна підготовка; push і створення PR на GitHub ще не виконані.

Застосунок зберігає товари, категорії, покупців і замовлення в PostgreSQL. Структура з п’яти таблиць у 3NF створюється та версіонується через Liquibase; доступ до даних реалізовано через Spring Data JPA.

## Зміни

- Liquibase changelog, sequence, зовнішні ключі, перевірки, індекси та унікальність email.
- JPA CRUD для товарів, категорій і замовлень зі збереженням чинного UUID API товарів.
- Транзакційне оформлення замовлення з історичними цінами та блокуванням залишків; скасування повертає залишки.
- Усі бонуси (+4 за умовою): унікальна назва товару в категорії, Natural ID замовлення, projection і JPQL-звіт із фільтрацією та сортуванням.
- PostgreSQL у Docker Compose, інтеграційні тести з Testcontainers, документація та приклади запитів.
- CI та JaCoCo вимагають щонайменше 80% покриття рядків усього основного коду.

## Розширення

- Пагінація, keyset, пошук і фільтри виконуються у БД; стабільні порядки за ID, назвою й ціною.
- Позиції NEW можна додавати, видаляти й змінювати атомарно зі складськими залишками.
- DELETE архівує товар, зберігаючи історію та забороняючи нові покупки.
- Чотири додаткові JPQL projection-звіти: категорії, виручка, покупці та товари без продажів.
- Нова міграція додає active та індекси; старі changeset не змінено.
- Тести перевіряють конкурентне скасування/редагування/покупку, rollback і межі дат.

- 175 тестів, без помилок і пропусків; 34 інтеграційні сценарії з PostgreSQL.

- Перевірено CRUD, міграції, обмеження, rollback, конкурентне резервування, Natural ID та звіт.

## Особливості

Для запуску потрібен PostgreSQL; для тестів — запущений Docker. Коди категорій залишені сумісними з попереднім API: TOYS, FOOD, ACCESSORIES. Детальні інструкції: `docs/lab3.md`; приклади: `docs/lab3.http`.
